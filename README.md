# Circuit Commons

Electronics Gadgets Resource & Knowledge Network

## Pages
- `index.html` — Home page
- `resources.html` — Resources
- `articles.html` — Articles
- `community.html` — Community
- `login.html` — Login
- `signup.html` — Sign up

## Run locally
Open `index.html` in a browser. No build tools are required.

## Notes
- Responsive HTML, CSS and vanilla JavaScript.
- Shared navigation, SVG favicon and styling across all pages.
- Authentication pages are front-end demo forms only. Connect a backend/auth provider for real registration, sign-in, password reset and secure session handling.
- Google Fonts are loaded online; system sans-serif fallbacks are provided.
